# IBM Bob sessions

This page indexes the IBM Bob task sessions used to set up, build and run EPOCH. Every task has a PNG screenshot of its consumption summary and the task history exported from Bob IDE 2.2 as JSON, both in [`bob_sessions/`](../bob_sessions/). File names follow the hackathon guide: team name (Fast & Curious), task number and a short description, for example `fastandcurious_task05_futures_a_b_summary.png`.

Only sessions with an export are listed. Every row is written from its export and from EPOCH's own records; nothing here is reconstructed after the fact.

All sessions ran on 27 Sep 2026 with the EPOCH API running locally. Hriday's ran in the workspace `E:\Projects\Epoch` on the branch `epoch-hriday`; Sarthak's ran on the branch `epoch-frontend`.

## How the sessions connect to EPOCH

- Bob reaches EPOCH through the `epoch` MCP server (`.bob/mcp.json`). Tool calls appear in each exported history.
- Workflows Bob starts are recorded in EPOCH with the author `IBM Bob`, so every mutation Bob produced can be found with `GET /api/mutations` and traced back to its workflow, plan, evidence and approval.
- Bob has no approve tool. Every approval in these sessions was a person's decision, made in the console or through the decision endpoint.
- Commits for Bob's work in this repository use the prefix `bob(<task>):` so they can be matched to the exported task. Tasks 02 to 07 were committed as `bob(02a)`, `bob(02)`, `bob(03)`, `bob(04)`, `bob(05)` and `bob(06)` before the files were renumbered to match Bob's task list; the table above gives each task's commits.
