Screenshots of the consumption summary are included where they were taken.

Only sessions with an export are listed. Every row is written from its export and from EPOCH's own records; nothing here is reconstructed after the fact.

## How the sessions connect to EPOCH

- Bob reaches EPOCH through the `epoch` MCP server (`.bob/mcp.json`). Tool calls appear in each exported history.
- Workflows Bob starts are recorded in EPOCH with the author `IBM Bob`, so every mutation Bob produced can be found with `GET /api/mutations` and traced back to its workflow, plan, evidence and approval.
- Bob has no approve tool. Every approval in these sessions was a person's decision, made in the console or through the decision endpoint.
- Commits for Bob's work in this repository use the prefix `bob(<task>):` so they can be matched to the exported task.
